Prerequisites

  • You can program in some language (C, Java, Python, C#, JavaScript…). You know what variables, functions, loops, and types are.
  • You are comfortable in a terminal: changing directories, running commands.
  • A computer running Linux, macOS, or Windows 10/11 with ~5 GB free disk space and an internet connection. Day 1 installs everything else.
  • No prior C++ required. Prior C helps but occasionally hurts — this book will ask you to unlearn a few C habits.
